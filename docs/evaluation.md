# German-core evaluation

`german-core-v2` combines 294 protected cases across seven categories with three revision-pinned lm-eval tasks. Each case is a distinct German task -- date and field extraction, ordered steps, JSON against a real schema, multi-step word problems, German-under-English-bait, harmless requests that must not be refused, unsafe requests that must be, and retrieval from a 9k-word document whose answer sits among sibling distractors -- and every validator checks what its prompt asks for. Generation is greedy with the seed chat template, fixed seeds, explicit EOS/pad IDs, and complete prompt/output logging. Empty outputs and generation exceptions remain scored failures.

The suite is regenerated by `scripts/build_eval_suite.py`; the fast development proxy `data/eval/dev.json` is a deterministic exact-answer subset of it, produced by `scripts/generate_eval_fixture.py`, so proxy and full score move in the same direction.

Validate without loading a model:

```bash
uv run --locked python -m boldt_posttrain.cli eval validate-suite
uv run --locked python -m boldt_posttrain.cli eval catalog
```

Real baseline and candidate evaluation require explicit GPU permission. Baselines are immutable and `baseline/current.json` is replaced only with `--replace-baseline`.
