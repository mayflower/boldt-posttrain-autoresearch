# Operations

Run bootstrap once with real GPU authorization. It discovers licensed German sources, writes the
deterministic selection artifact, atomically prepares data, and establishes an immutable dev
baseline. Re-running is idempotent because readiness is derived from verified artifacts.

Search plans contain at most nine explicit scalar override dictionaries. Trials execute serially at
64 additional steps, 192 additional steps, then the remaining full budget. Continuation loads the
trial's own adapter as trainable and uses a fresh optimizer; each rung is a new run card with its
parent recorded.

Promotion suites are registered by a human:

```bash
uv run pt eval register-promotion-suite --path /absolute/outside/repository/suite.json
export BOLDT_PROMOTION_SUITE=/absolute/outside/repository/suite.json
```

Run the manually dispatched GPU acceptance workflow on a runner labelled `gpu-48gb`. It performs
doctor checks, real QLoRA and RLOO steps, evaluation, reload, and chain validation without publishing
weights.
